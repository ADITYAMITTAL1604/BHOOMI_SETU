# Dual Repository Push Rule

Whenever instructed to push code changes to GitHub, always ensure changes are pushed to **both**:
1. **Original / Upstream repo**: `https://github.com/Singh4Ashmeet/BHOOMI_SETU.git`
2. **Forked repo**: `https://github.com/ADITYAMITTAL1604/BHOOMI_SETU.git`

The `origin` remote has been configured with dual push URLs so `git push origin main` will push to both repositories simultaneously. If individual pushes are made, push to both `origin` and `fork`.
